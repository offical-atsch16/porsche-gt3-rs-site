## Reporting a Vulnerability

We take the security of our project seriously and appreciate responsible disclosure of vulnerabilities.

If you discover a security vulnerability, please report it by opening a new issue and selecting the **Vulnerability Report** template. Please provide as much relevant information as possible, including:

- A detailed description of the vulnerability
- Steps to reproduce the issue
- Potential impact and affected versions
- Suggested mitigations or fixes (if available)

Our team will review all reports promptly and work to address confirmed vulnerabilities in a timely manner.

Thank you for helping us keep this project secure.
